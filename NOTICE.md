## Educational Context

This repository contains an educational cybersecurity portfolio project developed as part of the Per Scholas Cybersecurity with AI Tools program, Boston 2026 Cohort 04.

The project applies Python-based data analysis to a synthetic healthcare IT asset inventory. It evaluates simulated asset criticality, patch and lifecycle status, vulnerability indicators, exposure, data sensitivity, security-control coverage, and asset condition to support educational risk-triage analysis.
